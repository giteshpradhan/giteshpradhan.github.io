## 🎯 About This Project

This is my personal developer portfolio — a dark-themed, fully responsive web app built with **React 19 + Vite**. It showcases my skills, projects, education, and ways to reach me, all wrapped in a modern teal-and-dark aesthetic.

Designed from scratch with a focus on clean UI, smooth animations, and an experience that reflects my passion for **data analytics, Python development, and web engineering**.

---

## ✨ Features

- **🌙 Dark Mode Design** — Deep navy/charcoal background with vibrant teal accents throughout
- **🔷 Geometric Hero** — Hexagon-clipped profile photo with animated teal glow effect
- **📊 Projects Showcase** — Navigable cards featuring real projects in Python, Web Dev & Data Analysis
- **📄 Resume Section** — Education, skills breakdown, and a downloadable CV button
- **📬 Contact Section** — Direct links to email, LinkedIn, and phone
- **📱 Fully Responsive** — Optimized for mobile, tablet, and desktop breakpoints
- **⚡ Scroll Animations** — Fade-in and slide-up transitions as sections enter the viewport

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/portfolio-gitesh.git
   cd portfolio-gitesh
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages**
   ```bash
   npm run deploy
   ```
